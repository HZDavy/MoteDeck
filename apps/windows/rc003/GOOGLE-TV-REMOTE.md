# Google TV Remote 9451 设备与按键

| 设备 | 配置标识 | VID / PID |
| --- | --- | --- |
| Google TV Remote | `google-tv-remote` | `18D1 / 9451` |
| Chromecast Remote | `chromecast-remote` | `18D1 / 9450` |

配对扫描按蓝牙名称识别配置，接收时仍核验所选物理设备的 ContainerID 和 PnP 身份。
9451 的已知 PnP REV 为 `0105`；这不是通过设备菜单读取的固件版本。
同一设备从旧 `chromecast-remote` 配置迁移时，必须有本次扫描证据，并保留映射和设置。

9451 的前面板经所选设备的 Raw Input 集合进入映射。语音键镜像事件不在这个通道重复触发。
Home 和静音保留 Windows 原生行为；本改动不承诺对这两个键任意重映射。

侧边音量使用现有 Frida 能力观察 UMDF COPY，核验调用位置、接口和所选设备身份后，
才读取报告 ID 1 的七字节数据。读取长度来自已验证的输出缓冲区长度，
不能把内部调用的 `lpBytesReturned == 0` 当作没有报告。报告 ID 2 不在此重复交付。
该通路不修改系统报告、不安装新内核驱动，也不持久化原始按键报告。

侧边音量遇到已知终止性失败时单独降级并记忆状态；用户可在设备页重新开启。
其状态文件与米家 HID 补充通道分开。共用降级机制保留原 PR 作者的实现。
9450 继续使用独立接收子进程及原八字节回调，不启动主进程 Raw Input 或物理语音键钩子。

本分支只包含设备、配置迁移和按键通道。GATT 订阅及注入后端修复另行审查，
不包含应用启动扩展、输入法切换或语音槽界面重设计。支持状态保持 `research`。

历史综合版本曾经由用户确认普通键跨窗口、侧边音量及语音可用；
这些记录不是本分支最终提交的真机验收。提交审查前必须补齐对应提交的设备与系统版本、
操作步骤、脱敏日志和实际结果。9450、米家实机及其他固件仍需明确标注验证情况。
