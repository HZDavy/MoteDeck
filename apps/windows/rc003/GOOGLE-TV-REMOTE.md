# Google TV Remote 配置

Google TV Remote 与 Chromecast Remote 使用独立的配置标识：

| 蓝牙名称 | 配置标识 | VID / PID |
| --- | --- | --- |
| Google TV Remote | `google-tv-remote` | `18D1 / 9451` |
| Chromecast Remote | `chromecast-remote` | `18D1 / 9450` |

设备页读取已配对设备时，根据规范化的蓝牙名称选择对应配置。Google TV Remote
使用独立名称和按键说明，两种设备继续共享现有的遥控器布局、图片和谷歌接收运行时。
界面中的名称选择并不替代接收链路自身的设备身份校验。

## 已保存设备

旧版可能把 Google TV Remote 保存为 `chromecast-remote`。刷新已配对设备后，
对同一物理设备选择“使用”，会将其配置单向更新为 `google-tv-remote`。
更新保留设备身份键、按键映射和语音设置，并刷新当前布局与名称。
没有本次配对扫描证据时不会自动改写旧记录；其他设备的配置不变。

## 支持边界

9451 前面板按键使用属于所选设备的 Raw Input 集合。侧边音量通过现有 Frida
接收机制观察 UMDF 报告复制：验证调用位置、设备接口与所选 ContainerID 后，
才读取报告 ID 1 的七字节数据；报告 ID 2 的前面板输入不在此通路重复交付。
该路径不修改系统报告、不安装新内核驱动，也不保存原始按键报告。

9450 保留原来的八字节私有回调与模块、地址校验。9451 麦克风使用按 UUID 找到的
GATT 特征订阅，避免假定9450的特征句柄。复用上游的8 kHz转16 kHz音频处理与
语音注入后端选择；单独按住右 Alt 等修饰键不发送自动重复。

本地适配版本已经获得用户对普通按键跨窗口输出、侧边音量加减及豆包语音输入的
实机确认。本 PR 在最新上游重新集成，保留上游语音实现，并移除了临时诊断输出；
这些集成差异由自动测试覆盖，不能当作对最终分支的再次真机验收。

目录状态保持 `research`。主页与静音保留 Windows 原生行为，任意重映射尚未实现。
其他固件、RC003/9450实机回归、重连和长期运行仍需人工验收。
