# MoteDeck Windows 使用说明

MoteDeck把小米蓝牙语音遥控器 2 Pro（RC003）变成
Windows 的远程按键和语音输入设备。

**[下载页面与最新版说明](https://github.com/HZDavy/MoteDeck)**

正式版、测试版、支持设备和界面预览都以下载页面为准。历史版本可在
[Releases](https://github.com/HZDavy/MoteDeck/releases) 中查找。

## 下载与安装

- 系统要求：64 位 Windows 10 1809 或更高版本。
- 运行 `MoteDeckSetup-<版本号>-unsigned.exe`，按提示安装到当前用户目录
  `%LOCALAPPDATA%\MoteDeck`，并创建开始菜单与桌面快捷方式。
- 卸载：Windows 设置 → 应用 → MoteDeck → 卸载，或开始菜单中的卸载入口；
  配置、日志和录音保留在 `%LOCALAPPDATA%\RemoteMic\RC003`，需要彻底清理时手动删除。
- 程序暂未签名，首次运行可能出现 Windows SmartScreen 提示。请从本仓库下载，并用
  同一次发布中的 `SHA256SUMS.txt` 核对安装包。
- 如果旧版正在运行，先从通知区域图标选择“完全退出”，再运行新安装包。

核对哈希：

```powershell
Get-FileHash -Algorithm SHA256 .\MoteDeckSetup-<版本号>-unsigned.exe
```

输出的哈希应与 `SHA256SUMS.txt` 中同名文件完全一致。

## 第一次使用

### 1. 在 Windows 中配对遥控器

先打开 Windows“设置 → 蓝牙和设备”，让遥控器进入配对状态并完成配对。

小米遥控器 2 Pro 可同时长按“主页键 + 菜单键”进入配对状态。

### 2. 在MoteDeck中选择设备

1. 打开“设备”页，点击“选择设备”。
2. 选中刚配对的遥控器，点击“使用此设备”。
3. 点击“启动服务”，按页面提示处理黄色或红色状态。
4. 状态显示已连接后，按一次方向键或确定键确认按键可用。

软件会记住选中的那一只遥控器。切换设备时会先停止当前按键和录音，再连接新设备。

### 3. 设置按键

打开“按键”页，选择实体按键，再设置单击、双击或长按动作。点击“完成”后自动保存。

- 方向、确认、返回、音量、翻页、快捷键和 Quicker 动作可按界面选项配置。
- 长按动作只触发一次；允许连续执行的普通动作在持续按住时会重复。
- 语音1／语音2 可以放到任意按键，按下时会执行该槽录制的快捷键并请求开麦；但 RC003 只在实体话筒键被按住期间送出声音，主机主动开麦只得到开始控制、没有音频，所以真正能传声的用法仍是按住实体话筒键说话。
- 按键接收需要管理员组件时，程序会弹出一次 UAC。取消后自定义映射不会生效，
  可回到“设备”页重新启用或修复。

#### 当前开发版新增：鼠标长按与配置管理

以下功能对应 `1.0.90-candidate.90` 本地测试版，旧 `.89` ZIP 不包含，待实体遥控器验收。

- “长按”栏新增鼠标左键、右键、X1、X2 长按；按住约 0.55 秒后保持鼠标按下，
  遥控器松手即释放。这四项不出现在单击或双击栏。普通长按动作仍只触发一次。
  断线、停服务、切换设备和退出沿用输入清理；释放未确认时保留重试责任。
- 按键页顶部是一条应用条（仿 Logi Options+）：第一项固定是“全局”，之后每个已保存的
  应用一项，末尾的“+”用于新增应用。点击某项立即把下方按键列表切到该档案，没有额外的
  “应用配置”步骤；在按键页的编辑会按当前档案自动保存。
- 应用档案只保存被覆盖的按键，未覆盖的按键回退到全局映射。运行时会按前台进程名
  （不区分大小写的精确匹配）自动切换，也可给档案设置一个切换快捷键；当前生效的档案
  在应用条上带勾显示。默认只切换按键映射，不改动语音和音频设置。
- “全局”项代表当前的 `key_bindings.json`，不另外保存第二份运行配置，不能重命名或删除，
  可以复制、导出。
- “恢复内置默认”旁的“整体配置”打开导出／导入面板：把全局按键和全部应用档案打包成一个
  文件，便于整机迁移。导入会替换全局按键和全部应用档案并立即更新按键设置；导出位置由
  用户选择，不允许覆盖软件数据目录。
- 档案只包含当前型号，同型号设备可共用；仅保存单击、双击、长按动作和备注，不含设备身份、
  配对、真实按键检测结果、语音和音频设置。
- 删除应用需要确认，只删除该档案，全局按键和其它档案不变；当前生效的档案被删除后，
  生效标记回到“全局”。复制或重命名遇到同名会提示换名；导入遇到重名自动加序号，不覆盖已有档案。
- 当前映射含需要调整的旧动作时，仍可查看应用条、管理已有档案及导入有效配置；
  复制／导出前须先在按键页完成调整并保存。如果操作已保存成功但列表未能刷新，
  会提示重新打开面板查看，不把保存成功误报为失败。
- 默认数据文件为 `%LOCALAPPDATA%\RemoteMic\RC003\app_profiles.json`，不替换原来的
  `config.json`、`key_bindings.json`。导出位置由用户选择，导出的 JSON 可用于备份和导入；
  不允许导出覆盖软件数据目录。开发隔离会话仍使用自己的数据根目录。

档案库及导出格式的唯一实现为 `app_profiles.py`（`app_profiles.json`，版本 4）；旧的
`mapping_presets.json`（版本 1–3）在首次读取时原子迁移并保留原文件作为备份。
整体配置导出／导入格式为版本 1。档案库是用户数据，不纳入 Git 或程序包，不在恢复内置默认、
删除其它档案时自动清理。未知版本或损坏文件会明确报错并保留原文件。

### 4. 设置语音

如果要把遥控器声音送进搜狗、微信、豆包或 Chatterfly，需要安装并配置 VB-CABLE：

1. 打开“语音”页，点击“安装音频”，按提示安装后重启电脑。
2. MoteDeck的“输出端点”选择 `CABLE Input — Windows WASAPI`；没有 WASAPI 时，
   可选 `Windows DirectSound`。
3. 在输入法的麦克风设置中选择 `CABLE Output`。
4. 在MoteDeck中选择语音程序，刷新或手动录入该输入法的语音快捷键。Chatterfly
   使用其设置中的“语音输入”快捷键；首次选择不会继承其它输入法的快捷键。
   `1.0.91` 正式版支持从 Chatterfly 用户配置自动读取（旧 `1.0.87` 包仍需手动录入）。
   已保存的手动值须点击刷新才替换；多个账号配置、未启用或读取失败时保留原值。
   切换设备、切换录音模式或进入语音页时，搜狗、豆包、Chatterfly 的自动值会重新读取；
   当前正忙时等空闲后补读，手动值保持不变。微信仍须主动刷新，不会自动打开设置窗口。
   请避开系统及其它软件已占用的组合键。
5. 先在记事本中用实体键盘测试这个快捷键，确认输入法能够正常开麦和输入文字。
6. 保持光标在文字框内，再用遥控器话筒键测试。

`CABLE Input` 是MoteDeck写入声音的一侧，`CABLE Output` 是输入法读取麦克风的一侧，
方向不能互换。不要选择 `Windows WDM-KS`。

小米遥控器使用按住型：按住说话，松开结束。

`1.0.91` 正式版直接调用 Chatterfly 已有的录音开始／结束入口，小米按住操作保持原样；
已有录音时不重复开启。气泡出现后才转发遥控声音，结束后气泡应消失。
语音快捷键仍可读取和录入供键盘对照，但不再是遥控唤起的前提。此修复已通过本机真实
气泡开关验证；旧 `.87` 正式包及 `.89` 本地包仍使用旧的
模拟按键路径。实体遥控器传声和文字上屏仍待验收。

使用快捷键的按住型录音期间，语音快捷键会一直保持按下，松开话筒键才释放。请避开 Windows 和其它
软件已经占用的组合键，录音时不要同时操作其它键或鼠标。

## 日常使用

- 关闭设置窗口默认只是隐藏到通知区域，遥控器服务继续运行。
- 需要真正结束程序时，右键通知区域图标并选择“完全退出”。
- “随 Windows 启动”和“启动程序时自动运行服务”是两个独立选项，可分别设置。
- 服务断开时先按设备页提示“立即重连”或“重新连接”，无需反复启动多个程序。
- “检查更新”只提示和下载新版本，不会自动运行下载文件或覆盖当前安装。
- 更新时先完全退出旧版，再运行新下载的安装包；安装包会覆盖程序文件，个人配置保留。

## 常见问题

### 已配对，但设备列表里找不到

确认 Windows 蓝牙设置中仍能看到该遥控器，然后在“选择设备”窗口点击“刷新”。
软件只列出已支持的型号；有多只同类设备时，需要明确选择，不会自行猜测。

### 普通方向键有反应，自定义映射没有反应

检查“设备”页的“按键接收”状态。若提示权限或管理员组件异常，按页面入口修复并确认
UAC；若明确提示需要重启电脑，请保存工作后重启 Windows。

### 输入法能弹出气泡，但没有声音

检查MoteDeck是否选择 `CABLE Input`，输入法麦克风是否选择 `CABLE Output`，再运行
“检查虚拟声卡”。两边选反或选成同一个端点都会失败。

### 遥控器按语音键没有唤起输入法

先在同一个文字框中用实体键盘测试输入法快捷键。实体键盘也无法唤起时，先处理输入法
设置或快捷键冲突；实体键盘正常、遥控器失败时，再检查MoteDeck保存的模式和快捷键是否一致。

### 微信提示“已收到声音，未确认微信开麦”

此提示适用于 `.89` 及后续包含按住语音修复的构建，原 `.88` 本地测试包不含该修复。
它表示MoteDeck收到了遥控器声音，但未能确认微信本轮开始录音，不代表微信一定启动失败。
若文字正常出现，无需处理；若没有文字，先松开语音键，再按住重试。按住期间程序不会
因为查不到开麦状态而自行松键重按。

### 豆包或微信在远程控制窗口表现不同

部分远程控制窗口会影响输入法气泡或文字上屏。先在本机记事本验证，再判断是否属于远程
软件兼容问题。

### 仍然无法定位

在“设备”页点击“导出日志”，把 ZIP 和问题发生的大致时间、遥控器型号、所选输入法一起
提供。导出内容不包含录音、输入正文或用户配置。“打开日志位置”位于“导出日志”旁边，
可直接打开本机日志文件夹；关闭诊断记录后，这两个入口仍可使用。
导出遇到文件轮转或变化时，会重新读取一次；仍在变化、读取失败、截断或当前写入器
报告记录丢失时，会提示部分日志不完整，并在包内说明中标记。

## 配置、日志与卸载

用户配置和日志位于：

```text
%LOCALAPPDATA%\RemoteMic\RC003
```

删除免安装程序文件夹不会自动删除这里的数据。若开启过“随 Windows 启动”，移动或删除
程序前先在设备页关闭该选项。需要完全清除设置时，先完全退出MoteDeck，再自行删除上述目录。

## 当前限制

- 正式版与测试版支持范围不同，下载前请查看下载页面的版本说明。
- 程序未签名，受管理的公司电脑可能禁止 UAC、按键组件或虚拟音频安装。
- 管理员按键组件要求当前登录账号本身属于管理员组。
- 游戏或反作弊软件可能把模拟按键识别为自动化操作；请按目标软件规则使用。
- 输入法的联网、识别结果和文字润色由输入法自身决定。

## 隐私与第三方组件

MoteDeck不会把遥控器地址、按键记录、录音或个人数据上传到项目服务器。配置和日志保存在
本机；所选输入法是否联网由输入法自身决定。

VB-CABLE 是 VB-Audio 的独立 Donationware。代码与第三方说明见
[`ATTRIBUTION.md`](ATTRIBUTION.md)、仓库根目录
[`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md) 和
[`ASSET_LICENSES.md`](../../../ASSET_LICENSES.md)。
