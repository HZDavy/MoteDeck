连接前请先启动 MoteDeck，并在「语音」页开启插件连接。

通讯方式：插件与 MoteDeck 通过本机回环 TCP 直连（127.0.0.1 随机端口 + 共享 token），控制指令和遥控器音频都以 JSON 行传输，再由插件推进 Vokie 会话；不开插件时改走虚拟声卡，靠模拟快捷键唤起 Vokie。

关于 MoteDeck

MoteDeck 把蓝牙语音遥控器变成电脑上的语音键：不开插件时声音走虚拟声卡，开插件后直连 Vokie。这个插件负责接通两者，并把 Vokie 的语音模式同步到 MoteDeck 的语音键配置。

插件界面不能直接打开浏览器，点任意一项会复制链接，粘贴到浏览器即可。
